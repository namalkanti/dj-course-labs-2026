# Harmonics and Transitions

This module connects music-information-retrieval features with practical transition design.

## Topics

- **Chromagrams:** representations that pool spectral energy into pitch classes across octaves.
- **Key classification:** estimating tonal centers and mode from chroma features while accounting for ambiguity and short excerpts.
- **Camelot wheel compatibility:** using adjacent or compatible keys as a useful transition heuristic, then confirming with listening.
- **Gain curves:** shaping level changes so perceived loudness remains controlled through an overlap.
- **Crossfader summing curves:** comparing linear, equal-power, and custom curves to understand level, energy, and cancellation behavior during blends.

The exercises should pair visual analysis with critical listening: harmonic compatibility informs a transition, but arrangement, rhythm, and gain staging determine whether it lands cleanly.
