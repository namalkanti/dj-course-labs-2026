# Audio Test Fixtures for Quality Lab

This directory contains public-domain and openly licensed reference audio tracks for codec analysis and transcode detection:

1. **`persistence_by_dabmasterars_snippet.flac`** (2.5 MB, 20s snippet, 44.1 kHz / 16-bit FLAC)
   - **Track**: *Persistence*
   - **Author**: Arseniy "Dabmasterars" Danilovich Pozdeyev
   - **Source**: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Persistence_by_Dabmasterars.flac)
   - **License**: [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/)
   - **Modifications**: Clipped to 20s excerpt (00:30–00:50) via ffmpeg copy stream.
   - **Genre**: Minimal Techno (150 BPM, 808/909 kicks, open hi-hats, congas, analog synth stabs)
   - **Use case**: Pristine lossless reference showing full spectrum retention up to the 22.05 kHz Nyquist frequency.

2. **`high_technologic_beat_explosion_by_loyalty_freak_music_snippet.mp3`** (782 KB, 20s snippet, 44.1 kHz / 320 kbps MP3)
   - **Track**: *High Technologic Beat Explosion*
   - **Author**: Loyalty Freak Music
   - **Source**: [Free Music Archive](https://freemusicarchive.org/music/Loyalty_Freak_Music/ROBOT_DANCE_/Loyalty_Freak_Music_-_ROBOT_DANCE__-_02_High_Technologic_Beat_Explosion/)
   - **License**: [Creative Commons CC0 1.0 Universal (Public Domain Dedication)](https://creativecommons.org/publicdomain/zero/1.0/)
   - **Modifications**: Clipped to 20s excerpt (00:15–00:35) via ffmpeg copy stream.
   - **Genre**: Electronic / Synth Dance (128 BPM, four-on-the-floor kick, synth leads)
   - **Use case**: Genuine 320 kbps MP3 encoded via LAME 3.99r showing genuine high-bitrate perceptual coding (shelf around 20.0–20.5 kHz).
